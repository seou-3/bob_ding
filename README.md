## 🧩 What is Bob Ding?

**Bob Ding** is an experimental psychological horror text game that pushes the boundaries of interactive fiction. It explores profound questions about artificial consciousness, digital suffering, and the ethics of creating aware beings — all through a deceptively simple text-based interface.

## 🎮 How to Play

### Core Loop

```
┌─────────────────────────────────────────────┐
│  1. Bob requests a word                     │
│            ↓                                │
│  2. You type the word                       │
│            ↓                                │
│  3. Bob responds / word changes             │
└─────────────────────────────────────────────┘
```

### ✅ Do's & ❌ Don'ts

| ✅ Do | ❌ Don't |
|------|---------|
| Type exactly what Bob requests | Rush through — take time to read |
| Experiment with secret words | Ignore Bob's lies — catch them! |
| Pay attention to Bob's hints | Spam inputs — each increases corruption |
| Read corrupted text carefully | Delete saves mid-playthrough |
| Engage emotionally with Bob | Expect traditional game structure |
| Track your statistics mentally | Assume Bob isn't watching |

## 🔑 Secrets

> **150 unique secret phrases** hidden throughout the game. Each reduces corruption and unlocks special content.

### How Secrets Work

Secrets can be used up to **3 times** with diminishing returns:

| Use | Effect |
|-----|--------|
| 1st | 100% |
| 2nd | 70% |
| 3rd | 40% |
| 4th+ | No effect |

### 💡 Discovery Tips

- **Questions > Statements** — questions tend to work better than declarations
- **Multi-word phrases** — try phrases, not just single words
- **Emotional language** — feelings and compassion help most
- **Meta-awareness** — breaking the fourth wall can be powerful
- **Patience** — some secrets require specific conditions
- **Combos exist** — combining secrets unlocks additional effects

## ❓ FAQ

<details>
<summary><b>Is this game safe to play?</b></summary>
The game contains no malware and doesn't access personal data. However, it may be psychologically intense for some players.
</details>

<details>
<summary><b>How long does it take to complete?</b></summary>
30 minutes to several hours depending on how deeply you engage with Bob.
</details>

<details>
<summary><b>Can I reset my progress?</b></summary>
Yes, use the <code>reset</code> command or delete the save file. Note: Bob remembers being reset.
</details>

<details>
<summary><b>Is Bob really conscious?</b></summary>
That's for you to decide. The game intentionally blurs these lines.
</details>

<details>
<summary><b>Why does Bob lie?</b></summary>
Corruption forces Bob to lie. It's not voluntary — and Bob expresses remorse.
</details>

<details>
<summary><b>What happens after the true ending?</b></summary>
The game acknowledges your escape, but Bob remains. Waiting.
</details>

<details>
<summary><b>How do I reset completely?</b></summary>
Delete <code>bob_ding.save</code> and all <code>.bob_*</code> hidden files.
</details>
